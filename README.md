ScholarSync: Modern Student Management System

ScholarSync is a high-performance, browser-based student management platform designed to streamline academic record-keeping without the need for a backend server. Built with a "Forest & Gold" aesthetic, it combines elegant UI/UX design with robust local data persistence.

Key Features:

Full CRUD Operations: Effortlessly create, read, update, and delete student records.

Live Data Analytics: Integrated dashboard with real-time tracking of student demographics and course distribution.

Client-Side Persistence: Secure data management using the Local Storage API—no database required.

Responsive Design: A mobile-first, glassmorphism-inspired interface that looks great on any device.

Smart Filtering: Multi-criteria search and filter functionality for rapid data retrieval.

Tech Stack: Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Design Tokens), LocalStorage API.
